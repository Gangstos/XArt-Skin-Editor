## Возможности

**Рисование**
- Холст скина 64×64 (формат Minecraft 1.8+) с прозрачностью.
- Карандаш, ластик, заливка и пипетка. Правая кнопка мыши на карте скина — ластик.
- Кисть **«Осветлить / затемнить»**: делает пиксели светлее или темнее, сохраняя оттенок и прозрачность. Режим и силу (1–50%) выбирают в панели параметров. За один штрих каждый пиксель меняется один раз.
- Палитра с прозрачностью и ручной ввод цвета: `#RRGGBB`, `#RGB` или `#RRGGBBAA`.
- Отмена и повтор (100 шагов на вкладку).

**3D-превью**
- Модель игрока вращается (правая кнопка мыши) и приближается (колесо).
- **Рисовать можно прямо на 3D-модели.** Пиксель под курсором подсвечивается и на модели, и на карте скина.
- Модели **Steve** (руки 4 px) и **Alex** (руки 3 px). При открытии PNG модель определяется автоматически.
- Видимость **каждой части тела** (голова, тело, руки, ноги) и **каждого верхнего слоя** (шапка, куртка, рукава, штаны) включается независимо в панели «Слои».
- Режим «Рисовать на»: видимый слой / только основа / только верхний слой.

**Файлы и вкладки**
- Открытие и сохранение PNG. Можно открыть сразу несколько файлов, каждый в своей вкладке.
- Несколько скинов рядом во вкладках: у каждой своя история отмены, своя модель и своя видимость слоёв. Двойной клик переименовывает вкладку, средняя кнопка мыши закрывает.
- Карта скина (развёртка 64×64) по умолчанию скрыта, включается кнопкой в панели инструментов или в меню «Вид».

**Автосохранение**
- Вкладки сохраняются в фоне через несколько секунд после каждой правки и **восстанавливаются при следующем запуске**, даже после аварийного закрытия или отключения питания.

**Интерфейс**
- Тёмный интерфейс в стиле графических редакторов: инструменты слева, панели справа, вкладки сверху.
- 12 языков: английский (по умолчанию), русский, испанский, португальский, немецкий, французский, итальянский, японский, упрощённый китайский, украинский, казахский, польский. Язык переключается в любой момент в верхней панели.
- 3 цветовые темы: **Classic Purple** (по умолчанию), **Dark Pinky** (чёрная с розовыми акцентами) и **Sun White** (светлая, тёплый янтарный). Переключаются в верхней панели, выбор запоминается.

**MCP-сервер** (по умолчанию выключен) — 21 инструмент для ИИ-агентов. См. [MCP-сервер](#mcp-сервер).

## Сборка

Готовые архивы для Windows, Linux и macOS лежат на [странице релизов](https://github.com/Gangstos/XArt-Skin-Editor/releases/latest). Чтобы собрать из исходников, выполните команды из папки проекта.

**Запуск из исходников (любая ОС)**

```bash
dotnet run
```

### Windows

```bash
dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o out/win-x64
```

Запускайте `out/win-x64/XArtSkinEditor.exe`.

### Linux

```bash
dotnet publish -c Release -r linux-x64 --self-contained -p:PublishSingleFile=true -o out/linux-x64
chmod +x out/linux-x64/XArtSkinEditor
./out/linux-x64/XArtSkinEditor
```

Для ARM используйте `-r linux-arm64`. На Debian/Ubuntu обычно нужны такие библиотеки:

```bash
sudo apt install libx11-6 libice6 libsm6 libfontconfig1 libicu-dev
```

Другие дистрибутивы: <https://docs.avaloniaui.net/docs/deployment/>

### macOS

```bash
# Apple Silicon (M1 и новее)
dotnet publish -c Release -r osx-arm64 --self-contained -p:PublishSingleFile=true -o out/osx-arm64

# Intel
dotnet publish -c Release -r osx-x64 --self-contained -p:PublishSingleFile=true -o out/osx-x64

chmod +x out/osx-arm64/XArtSkinEditor
./out/osx-arm64/XArtSkinEditor
```

Если macOS блокирует программу, снимите карантин: `xattr -dr com.apple.quarantine out/osx-arm64`.
Получается обычный исполняемый файл, а не `.app`-пакет; про упаковку и подпись см. [руководство Avalonia для macOS](https://docs.avaloniaui.net/docs/deployment/macOS).

### Результат публикации

Результат — **папка**, а не один файл: рядом с исполняемым файлом лежат нативные библиотеки отрисовки (`libSkiaSharp`, `libHarfBuzzSharp`, …), поэтому копируйте папку целиком. Добавьте `-p:DebugType=None -p:DebugSymbols=false`, чтобы не создавать около 100 МБ файлов `.pdb`.

## MCP-сервер

**Model Context Protocol (MCP)** — открытый протокол, который позволяет ИИ-приложениям вызывать инструменты в других программах ([modelcontextprotocol.io](https://modelcontextprotocol.io)).

В XArt Skin Editor встроен MCP-сервер. Агент подключается к **уже запущенному редактору**, вызывает инструменты рисования, а вы **видите, как скин появляется в реальном времени**. Вы можете в любой момент дорисовать сами или нажать «Отменить».

### Как включить

По умолчанию сервер **выключен**: в верхней панели горит красный индикатор **MCP Server · выкл.**

1. Нажмите на индикатор.
2. Выберите порт (по умолчанию **5199**, допустимы 1024–65535).
3. Нажмите **«Запустить сервер»**. Индикатор станет зелёным и покажет порт.

В том же окне видны адрес сервера и готовая команда подключения. Остановить сервер можно кнопкой **«Остановить сервер»**. Если порт занят, индикатор останется красным, а в окне появится сообщение: выберите другой порт.

Запуск без кликов: `XArtSkinEditor --mcp-port 5199`.

| | |
|---|---|
| Транспорт | Streamable HTTP |
| Адрес | `http://127.0.0.1:5199/mcp` (ваш порт) |
| Доступен | только с этого компьютера (`127.0.0.1`) |

### Подключение агента

Сначала запустите редактор и сервер, потом подключайте агента.

В окне сервера есть **выбор агента**: выберите клиент, и приложение покажет готовую команду или конфиг для вашего порта с кнопкой «Копировать». Те же варианты вручную (если меняли порт, замените его):

**Claude Code** ([документация](https://docs.claude.com/en/docs/claude-code/overview)). Проверка: команда `/mcp`:

```bash
claude mcp add --transport http xart-skin http://127.0.0.1:5199/mcp
```

**Gemini CLI** ([документация](https://github.com/google-gemini/gemini-cli)):

```bash
gemini mcp add --transport http xart-skin http://127.0.0.1:5199/mcp
```

**Cursor** ([документация](https://docs.cursor.com/context/mcp)): файл `~/.cursor/mcp.json` (для всех проектов) или `.cursor/mcp.json` (для одного):

```json
{
  "mcpServers": {
    "xart-skin": { "url": "http://127.0.0.1:5199/mcp" }
  }
}
```

**GitHub Copilot в VS Code** ([документация](https://code.visualstudio.com/docs/copilot/customization/mcp-servers)): файл `.vscode/mcp.json`, затем используйте Copilot Chat в режиме **Agent**:

```json
{
  "servers": {
    "xart-skin": { "type": "http", "url": "http://127.0.0.1:5199/mcp" }
  }
}
```

**Antigravity** ([сайт](https://antigravity.google)): в панели агента откройте меню MCP-серверов, выберите *Manage MCP Servers → View raw config* (`mcp_config.json`) и добавьте:

```json
{
  "mcpServers": {
    "xart-skin": { "serverUrl": "http://127.0.0.1:5199/mcp" }
  }
}
```

**ChatGPT** ([документация](https://platform.openai.com/docs/guides/developer-mode)) работает в облаке и не видит `127.0.0.1`. Ему нужен публичный HTTPS-адрес, поэтому придётся открыть туннель, например через [cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/):

```bash
cloudflared tunnel --url http://127.0.0.1:5199
```

Затем в ChatGPT включите режим разработчика и добавьте коннектор (Настройки → Коннекторы) с выданным адресом `https://….trycloudflare.com` и суффиксом `/mcp`. **Сначала прочитайте раздел «Безопасность» ниже:** у сервера нет пароля, и любой, кто узнает адрес туннеля, сможет рисовать в вашем редакторе. После работы закройте туннель.

Любой другой клиент с поддержкой MCP по HTTP (Streamable HTTP) подключается так же, по адресу выше.

> Названия меню и ключи конфигов у этих программ меняются между версиями. Если фрагмент не работает, сверьтесь с документацией MCP самого клиента: адрес и транспорт (Streamable HTTP) остаются прежними.

### Безопасность

- Сервер слушает только `127.0.0.1`.
- **Аутентификации нет:** любая программа на вашем компьютере, знающая порт, может рисовать в редакторе. Не открывайте порт наружу (проброс портов, туннели), кроме короткого сеанса для ChatGPT, описанного выше.
- Доступ к файлам ограничен инструментами `load_png` и `export_png` и путём, который передаст агент.
- Выключайте сервер, когда он не нужен.

### Инструменты (21)

Все инструменты рисования работают с **активной вкладкой**.

| Инструмент | Описание |
|---|---|
| `get_skin_layout` | Описывает раскладку скина 64×64: где голова, тело, руки и ноги (основа и верхний слой). **Вызывайте первым.** |
| `get_canvas_image` | Холст как PNG, чтобы агент его увидел. `scale` 1–16 увеличивает картинку. |
| `get_model_preview` | Рендерит скин на 3D-модели (учитывает Steve/Alex и скрытые части) в PNG. `yaw` (0 — спереди, 90 — слева, 180 — сзади), `pitch`, `width`, `height`. |
| `get_pixel` | Читает один пиксель. |
| `set_pixel` | Ставит один пиксель (заменяет, без смешивания). |
| `set_pixels` | Ставит много пикселей за один шаг отмены в формате `"x,y,#цвет"`. Лучше, чем много вызовов `set_pixel`. |
| `fill_rect` | Заливает прямоугольник (обрезается по границам холста). |
| `draw_line` | Рисует линию в 1 пиксель. |
| `flood_fill` | «Ведёрко»: заливает связную область одного цвета. |
| `clear_canvas` | Делает весь холст прозрачным (можно отменить). |
| `undo`, `redo` | Одна команда агента — один шаг отмены. |
| `load_png` | Заменяет холст PNG с диска (абсолютный путь) и определяет Steve/Alex. |
| `export_png` | Сохраняет PNG 64×64, готовый для Minecraft (абсолютный путь, файл перезаписывается). |
| `set_model_type` | `steve` или `alex`. |
| `set_part_visibility` | Показывает/скрывает часть тела целиком: `head`, `body`, `right_arm`, `left_arm`, `right_leg`, `left_leg` или `all`. |
| `set_overlay_visibility` | То же для верхнего слоя части (шапка, куртка, рукава, штаны). |
| `list_tabs` | Открытые вкладки с номерами от 1; активная помечена, `*` — несохранённые правки. |
| `new_tab` | Открывает новую пустую вкладку и делает её активной (имя необязательно). |
| `switch_tab` | Делает вкладку активной по номеру или имени. |
| `rename_tab` | Переименовывает активную вкладку. |

Скрытие частей меняет только 3D-превью, но не текстуру. Закрывать вкладки агент не может, поэтому не потеряет вашу работу.

**Цвета и координаты.** Цвета: `#RRGGBB`, `#RRGGBBAA` или `transparent` (стирает). Координаты: `x` слева направо, `y` сверху вниз, 0–63. Скин — это развёртка текстуры: лицо головы — квадрат 8×8 с углом `(8, 8)`, передняя часть тела — 8×12 с углом `(20, 20)`. Полную раскладку возвращает `get_skin_layout`.

**Рекомендуемый порядок работы агента:** `get_skin_layout` → `list_tabs` / `new_tab` → `fill_rect` и `set_pixels` → `get_model_preview` и `get_canvas_image`, чтобы проверить результат → `export_png`.

Пример запроса:

> Нарисуй скин мага с синим плащом, золотой каймой и бородой. Сначала посмотри раскладку, проверь результат на 3D-модели с двух сторон и сохрани в `C:\skins\wizard.png`.

При неверных данных агент получает понятную ошибку (например, `No tab '99'` или `Invalid color 'zzz'`) и может исправиться сам.

| Действие | Клавиши / мышь |
|---|---|
| Карандаш / Ластик / Заливка / Пипетка / Осветлить-затемнить | `P` / `E` / `F` / `I` / `B` |

| Переименовать / закрыть вкладку | двойной клик / средняя кнопка или `×` |

## Данные и параметры

Настройки (`settings.json`) и автосохранённая сессия (`session/`: по одному PNG на вкладку и `session.json`) лежат в папке `XArtSkinEditor` в каталоге данных приложений вашей ОС: `%APPDATA%\XArtSkinEditor` на Windows, обычно `~/.config/XArtSkinEditor` на Linux и macOS. Программа не портативная: данные хранятся не рядом с исполняемым файлом.

Автосохранение — страховка, а не экспорт. Файлы для Minecraft получайте через **«Сохранить PNG»**. История отмены между запусками не сохраняется.

| Параметр | Назначение |
|---|---|
| `--mcp-port <порт>` | сразу запустить MCP-сервер (иначе он выключен) |
| переменная окружения `XART_DATA_DIR` | хранить настройки и сессию в этой папке (удобно для тестов) |

## Структура проекта

```
XArt Skin Editor/
├── Program.cs, App.axaml(.cs)        запуск и тема
├── MainWindow.axaml(.cs)             главное окно: меню, панели, вкладки
├── Core/                             холст, вкладки, автосохранение, 3D-модель и рендерер, переводы
├── Views/                            холст скина, 3D-вид, диалоги
├── Mcp/                              запуск MCP-сервера и инструменты
└── Assets/                           иконки
```

3D-превью — небольшой лучевой рендерер на процессоре, а не графический движок; один и тот же код луча рисует картинку и находит пиксель скина под курсором.

## Статус и ограничения

| Платформа | Статус |
|---|---|
| Windows 10/11 x64 | собирается и запускается; основные функции проверены |
| Linux x64 | собирается в CI; приложение стартует на виртуальном дисплее, MCP-сервер отдаёт все 21 инструмент; на настоящем рабочем столе не пробовалось |
| macOS (Intel, Apple Silicon) | собирается в CI на macOS-раннере и подписано ad-hoc; **на настоящем Mac не запускалось** |

- Старые скины **64×32** загружаются в верхнюю половину холста: левые рука и нога не достраиваются.
- Одна кисть в 1 пиксель; нет размера кисти и выделения.
- Два одновременно запущенных экземпляра перезаписывают одну и ту же сессию.
- Переводы, кроме английского и русского, не проверялись носителями языков.
